# DatFiles

Modular DAT overrides for Final Fantasy XI via **[XIPivot](https://github.com/Darkdoom/XIPivot)**.

## Installation

Drop the pack folder into your XIPivot directory:

`	ext
Windower4/addons/XIPivot/data/DATs/
└── Tronmenos/
    └── ROM3/3/82.DAT
`

Enable in XIPivot:
`	ext
//pivot add Tronmenos
`
